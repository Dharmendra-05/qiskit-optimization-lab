# Fundamentals: Understanding Quantum Optimization

This document provides a beginner-friendly, mathematically rigorous guide explaining every concept behind the **Quantum Resource Optimizer**, bridging intuitive ideas to the actual equations implemented in Python and Qiskit.

---

## 1. What is an Optimization Problem?

In everyday life and engineering, we constantly face decisions where we have multiple choices and limited resources:
- A logistics manager wants to deliver packages using the shortest possible driving distance.
- A factory manager wants to schedule shifts so workers don't get fatigued while meeting production targets.
- A clean-energy fund wants to invest in renewable energy projects to maximize clean electricity generated while staying within a fixed budget.

An **optimization problem** is the mathematical formalization of this challenge:
1. **Decision Variables ($x$):** The choices we can make.
2. **Objective Function ($f(x)$):** A numerical score evaluating how good a choice is (e.g. total profit, carbon offset, or travel time).
3. **Constraints:** Rules that must be respected (e.g. "total cost cannot exceed \$10M", or "choose exactly 2 projects").

---

## 2. Binary Variables and Feasible Solutions

In combinatorial selection problems, each choice is binary: **Yes (1) or No (0)**.
For example, if we have $n = 4$ candidate green energy projects:
- $x_0 = 1$ means we fund Project 0; $x_0 = 0$ means we do not.
- A candidate solution is represented as a bitstring of length $n$, such as $x = [1, 0, 1, 0]$.

### Feasible vs. Infeasible Solutions
If the organization has a strict budget permitting funding for **exactly 2 projects**, the constraint is:
$$\sum_{i=0}^{n-1} x_i = 2$$
- $x = [1, 0, 1, 0]$ has $1 + 0 + 1 + 0 = 2$ selected assets: **Feasible**.
- $x = [1, 1, 1, 0]$ has $1 + 1 + 1 + 0 = 3$ selected assets: **Infeasible** (violates budget).

---

## 3. From Constrained Optimization to QUBO

Classical optimization algorithms often handle hard constraints using branching or simplex methods. Quantum computers, however, naturally evaluate unconstrained energy landscapes.

To handle constraints on quantum hardware, we use **Quadratic Unconstrained Binary Optimization (QUBO)**.
We incorporate the constraint directly into the cost function by adding a **quadratic penalty term**:
$$C(x) = -\text{Utility}(x) + \lambda \cdot \left(\sum_{i=0}^{n-1} x_i - B\right)^2$$
where:
- $\text{Utility}(x)$ is the benefit of the selected portfolio (high is good; so $-\text{Utility}(x)$ minimizes).
- $B$ is the required budget (number of assets).
- $\lambda > 0$ is the **penalty multiplier**.

### How the Penalty Operates:
- If a bitstring satisfies $\sum x_i = B$, then $(\sum x_i - B) = 0$, so the penalty is $0$.
- If a bitstring violates the budget (e.g. selects 1 or 3 assets instead of 2), $(\sum x_i - B)^2 \ge 1$. The penalty adds $\ge \lambda$ to the total cost, making infeasible states high-energy (undesirable).

---

## 4. The Ising Model: Mapping Bits to Qubits

Quantum physics naturally describes systems of interacting two-level quantum spins (qubits). In the **Ising model**, each spin $s_i$ can point up ($+1$) or down ($-1$).

We map classical binary bits $x_i \in \{0, 1\}$ to quantum Pauli-$Z$ operators with eigenvalues in $\{+1, -1\}$ using the affine transformation:
$$x_i = \frac{I - Z_i}{2}$$

Let us verify this substitution:
- When a qubit is in state $|0\rangle$, the Pauli-$Z$ operator acts as $Z|0\rangle = +1 |0\rangle$.
  Then $x_i = \frac{1 - (+1)}{2} = 0$.
- When a qubit is in state $|1\rangle$, the Pauli-$Z$ operator acts as $Z|1\rangle = -1 |1\rangle$.
  Then $x_i = \frac{1 - (-1)}{2} = 1$.

### Deriving Two-Qubit Interactions
When two assets interact (e.g. risk covariance $\Sigma_{ij} x_i x_j$ or pairwise penalty terms):
$$x_i x_j = \left(\frac{I - Z_i}{2}\right)\left(\frac{I - Z_j}{2}\right) = \frac{1}{4}\left(I - Z_i - Z_j + Z_i Z_j\right)$$
Notice the $Z_i Z_j$ term! On a quantum computer, $Z_i Z_j$ corresponds to a two-qubit interaction (entanglement generated by $ZZ$ phase rotations, implemented with CNOT and $RZ$ gates).

Substituting this into the QUBO produces the **Cost Hamiltonian**:
$$\hat{H}_C = \sum_{i < j} J_{ij} Z_i Z_j + \sum_i h_i Z_i + \text{offset} \cdot I$$
The ground state (lowest energy state) of $\hat{H}_C$ is precisely the bitstring $x^*$ that minimizes the classical cost function $C(x)$.

## 5. The Quantum Approximate Optimization Algorithm (QAOA)

QAOA is a hybrid quantum-classical algorithm proposed by Farhi, Goldstone, and Gutmann (2014).

### Step 1: Initial State Preparation
We start with all $n$ qubits in an equal superposition of all $2^n$ possible bitstrings simultaneously:
$$|+\rangle^{\otimes n} = \frac{1}{\sqrt{2^n}} \sum_{x \in \{0, 1\}^n} |x\rangle$$
This is prepared by applying a Hadamard ($H$) gate to every qubit.

### Step 2: Alternating Quantum Layers
For depth $p$ (e.g. $p=1$ or $p=2$), the quantum circuit alternates between two unitary transformations:
1. **Cost Unitary $U_C(\gamma_k) = e^{-i \gamma_k \hat{H}_C}$:** Applies a phase shift proportional to the classical cost of each state. Good states acquire distinct phases.
2. **Mixer Unitary $U_M(\beta_k) = e^{-i \beta_k \hat{H}_M}$:** Uses the transverse field mixer $\hat{H}_M = \sum_{i=0}^{n-1} X_i$. It creates constructive and destructive interference, shifting quantum amplitude toward lower-energy states.

The trial state after $p$ layers is:
$$|\psi(\vec{\gamma}, \vec{\beta})\rangle = \left( \prod_{k=1}^p e^{-i \beta_k \hat{H}_M} e^{-i \gamma_k \hat{H}_C} \right) |+\rangle^{\otimes n}$$

### Step 3: Classical Optimization Loop
A classical optimizer (such as **COBYLA**) evaluates the expected energy:
$$E(\vec{\gamma}, \vec{\beta}) = \langle \psi(\vec{\gamma}, \vec{\beta}) | \hat{H}_C | \psi(\vec{\gamma}, \vec{\beta}) \rangle$$
using Qiskit's `StatevectorEstimator`. The classical routine iteratively updates the $2p$ parameters $(\vec{\gamma}, \vec{\beta})$ to minimize $E$.

### Step 4: Measurement and Solution Sampling
Once optimal angles $(\vec{\gamma}^*, \vec{\beta}^*)$ are found, we measure the qubits using `StatevectorSampler`.
Measurement collapses the quantum superposition into classical bitstrings. The states with the highest probability amplitude are our candidate portfolio solutions!

---

## 6. How Measurement Results are Decoded

Qiskit orders qubits in **little-endian format**:
In a bitstring `"b_{n-1} ... b_1 b_0"`, the **rightmost character** corresponds to qubit $0$.
To properly extract asset decisions:
$$\text{Asset } i \text{ assignment} = \text{integer value of bit at index } i \text{ (reversed bitstring)}$$
Each measured bitstring is independently evaluated against:
1. Budget Feasibility: $\sum_{i=0}^{n-1} x_i == B$.
2. Portfolio Return: $r^T x$.
3. Covariance Risk: $\frac{1}{2} x^T \Sigma x$.
4. True Utility: $\mathcal{U}(x) = r^T x - \frac{q}{2} x^T \Sigma x$.

---

## 7. Performance Metrics Defined

1. **Approximation Ratio ($\alpha$):**
   $$\alpha = \frac{\mathcal{U}(x_{\text{QAOA}})}{\mathcal{U}(x_{\text{optimal}})}$$
   - $\alpha = 1.0$: The quantum algorithm found the exact optimal portfolio.
   - $\alpha \in [0.8, 1.0]$: High-quality near-optimal solution.
2. **Feasibility Yield ($Y_{\text{feas}}$):**
   $$Y_{\text{feas}} = \frac{N_{\text{feasible shots}}}{N_{\text{total shots}}} \times 100\%$$
   Measures the percentage of measured outcomes that satisfy the exact budget constraint.

---

## 8. Why Simulation Does Not Prove Quantum Advantage

It is critical to maintain scientific rigor:
- **Statevector Simulation:** Our simulation runs on a classical laptop by multiplying $2^n \times 2^n$ statevectors. This is feasible only for small numbers of qubits ($n \le 20$).
- **NISQ Reality:** On real physical quantum hardware, two-qubit gates have error rates ($\sim 0.1\% - 1\%$), coherence times are finite ($T_1, T_2$), and physical qubit layout requires routing via SWAP gates.
- **Quantum Advantage:** True quantum advantage requires hundreds of error-corrected logical qubits or noise-mitigated utility-scale circuits solving problems beyond the reach of classical supercomputers ($n > 100$). QAOA on 4–8 qubits is a pedagogical demonstration of the quantum algorithm pipeline, not a proof of speedup.
