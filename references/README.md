# Reference Materials and Citations

This directory catalogues official literature, documentation, and external references utilized throughout the development of the **Quantum Resource Optimizer** project for Qiskit Fall Fest 2026.

## Curated Sources

1. **Farhi, E., Goldstone, J., & Gutmann, S.** (2014).
   *A Quantum Approximate Optimization Algorithm*.
   arXiv:1411.4028 [quant-ph].
   - Foundational formulation of QAOA, alternating cost and mixer unitary operations, and approximation ratios.

2. **Lucas, A.** (2014).
   *Ising formulations of many NP problems*.
   *Frontiers in Physics*, 2, 5. https://doi.org/10.3389/fphy.2014.00005
   - Exact mapping rules for translating linear and quadratic equality/inequality constraints into Ising and QUBO Hamiltonians with penalty multipliers.

3. **Markowitz, H.** (1952).
   *Portfolio Selection*.
   *The Journal of Finance*, 7(1), 77–91. https://doi.org/10.1111/j.1540-6261.1952.tb01525.x
   - Modern Portfolio Theory establishing expected return maximization penalized by covariance risk volatility.

4. **Sachdeva et al.** (2024).
   *Quantum optimization on a 127-qubit gate-model IBM quantum computer*.
   arXiv:2406.01743 [quant-ph].
   - Benchmarking utility-scale binary optimization with error suppression and noise characterization.

5. **IBM Quantum Documentation & Tutorials:**
   - *Quantum Approximate Optimization Algorithm Tutorial*: https://quantum.cloud.ibm.com/docs/tutorials/quantum-approximate-optimization-algorithm
   - *Qiskit Optimization Documentation*: https://qiskit-community.github.io/qiskit-optimization/
   - *BasQ Qiskit Fall Fest 2026 Reference Notebook* (Benjamin Tirado).
